# Безопасность

Boosty ATV — неофициальный клиент, который хранит сессию Boosty и передаёт её
на телевизор по локальной сети. Если вы нашли уязвимость, пожалуйста, не
открывайте публичный issue.

Напишите автору приватно: [@cergo666](https://github.com/cergo666) или через
GitHub Security Advisories репозитория.

В сообщении укажите версию приложения, версию Android, шаги воспроизведения и
ожидаемое/фактическое поведение. Не прикладывайте реальные токены, номера
телефонов и HAR-файлы с действующей сессией.
