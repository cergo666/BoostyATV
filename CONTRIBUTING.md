# Участие в разработке

Спасибо за интерес к Boosty ATV. Проект — неофициальный клиент Boosty для Android TV и телефонов.

## Перед началом

- Для сборки нужны JDK 21 и Android SDK Platform 37. Путь к SDK указывается в `ANDROID_HOME` или `local.properties`.
- Не коммитьте `local.properties`, `keystore.properties`, ключи подписи и HAR-файлы с токенами.
- Не добавляйте в код реальные токены, номера телефонов и другие персональные данные. Для тестов используйте синтетические значения.

## Проверка перед pull request

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --parallel
```

Для инструментальных тестов нужен подключённый телефон, ТВ или эмулятор:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

## Стиль кода

- Java 17, отступ 4 пробела, UTF-8, переводы строк LF (см. `.editorconfig`).
- UI приложения пока собирается программно; сохраняйте существующий стиль и переиспользуйте помощники из `Ui`.
- Пользовательские строки выносите в `res/values/strings.xml` (английский, язык по умолчанию) и `res/values-ru/strings.xml` (русский). Списки строк — в `arrays.xml` соответствующих каталогов.
- Не копируйте код из проектов с несовместимой лицензией. Если добавляете чужой код, обновите `NOTICE` и `LICENSE`.
- Не используйте `&&` в примерах для Windows PowerShell — в README используются команды, совместимые с PowerShell.

## Коммиты

Один коммит — одна логическая правка. В сообщении используйте префикс (`feat:`, `fix:`, `build:`, `test:`, `docs:`, `chore:`, `refactor:`). Перед пушем убедитесь, что сборка, unit-тесты и lint проходят.

## Безопасность

Сессия Boosty хранится зашифрованной через Android Keystore. Не ослабляйте проверки HTTPS, whitelist хостов WebView и шифрование сопряжения ТВ. Об уязвимостях сообщайте приватно автору, а не в публичном issue.
